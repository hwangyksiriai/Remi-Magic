# Windows 요술봉 간편 적용

`Remi-Magic-Setup.exe` 하나를 열고 **요술봉 적용하기**를 누릅니다. 원래대로 돌아가려면 같은 파일을 다시 열고 **원래 마우스로 돌리기**를 누릅니다. 원본 백업이 없는 경우에는 현재 마우스를 그대로 유지합니다.

다운받는 사람에게 Node.js, npm, 관리자 권한은 필요하지 않습니다. Windows 10·11의 .NET Framework를 사용합니다. 파일에는 디지털 서명이 없으므로 Windows 또는 브라우저가 보안 확인을 표시할 수 있습니다. 보안 설정을 끄거나 실행 정책을 변경하지 않습니다.

이 프로그램은 움직이는 구슬이 있는 요술봉 커서만 적용합니다. 소리, 잔상, 캐릭터 변신은 포함하지 않습니다. 일반 포인터와 링크 위의 포인터만 변경하며, 앱이 자체 커서를 그리면 적용되지 않을 수 있습니다. 실제 표시 크기는 Windows의 마우스 설정을 따릅니다. 큰 해상도 파일을 사용하더라도 Windows가 더 작은 커서로 표시할 수 있으므로 별도의 크기 선택은 제공하지 않습니다.

## 개발자 빌드

프로젝트 루트에서 Windows용 Node.js로 다음 명령을 실행합니다.

```sh
node scripts/build-windows-setup.mjs
```

또는 PowerShell에서 `scripts/build-windows-setup.ps1`을 실행합니다. 두 빌드 방법은 Windows에 있는 `.NET Framework v4.0.30319/csc.exe`로 동일한 C# 소스를 컴파일합니다. 외부 패키지 다운로드, 관리자 권한 또는 실행 정책 우회는 사용하지 않습니다. 빌드 결과는 `dist/windows-setup/Remi-Magic-Setup.exe`입니다.

두 가지 `.ani` 리소스와 `asInvoker` 매니페스트가 EXE에 포함됩니다. 기본 빌드는 자동으로 격리된 자체 검사를 실행합니다. GUI를 열거나 현재 사용자 커서를 변경하지 않는 검사입니다.

```text
Remi-Magic-Setup.exe --self-test --report 검사결과.txt
Remi-Magic-Setup.exe --preview 설정화면.png
Remi-Magic-Setup.exe --help
```

`--preview`는 투명한 화면 밖 창에 UI를 그려 PNG만 저장합니다. 마우스 설정에는 접근하지 않습니다. 정상 실행도 버튼을 누르기 전에는 설정을 변경하지 않습니다.

## 저장과 복원

- 요술봉 파일: `%LOCALAPPDATA%\RemiMagic\Cursors`
- 원본 백업: `%LOCALAPPDATA%\RemiMagic\cursor-backup.dat`
- 변경하는 레지스트리 값: `HKCU\Control Panel\Cursors`의 `Arrow`, `Hand`만

처음 적용하기 전에 두 값의 존재 여부, 원래 값, 값 형식을 보관합니다. `REG_EXPAND_SZ`는 환경 변수를 펼치지 않고 보관합니다. 여러 번 적용해도 원본 백업은 덮어쓰지 않습니다. 적용 중 오류가 나면 변경 직전 상태로 복구를 시도하고 원본 백업을 유지합니다. 복구까지 실패하면 오류를 알립니다.

복원에 성공한 경우에만 활성 백업을 지웁니다. 나중에 다시 적용하면 그때의 커서를 새 원본으로 보관합니다. 커서 파일은 안정적인 저장 위치에 남으므로 내려받은 EXE를 옮겨도 적용된 커서가 끊기지 않습니다. 안전을 위해 다른 파일이나 커서 폴더를 자동 삭제하지 않습니다.

백업은 전체 구조와 SHA-256 검증을 거칩니다. 손상된 백업은 덮어쓰지 않고 작업을 중단합니다. 저장 폴더의 심볼릭 링크·정션 및 내용이 바뀐 기존 커서 파일도 거부합니다. 같은 사용자에게 설정 창이 여러 개 뜨지 않도록 사용자별 뮤텍스를 사용합니다.

자체 검사는 가짜 레지스트리 저장소와 임시 폴더만 사용해 첫 적용, 반복 적용, 정확한 복원, 백업 없는 복원, 새 원본 재보관, 쓰기·새로고침 실패의 복구, 복원 재시도, 백업 손상·저장 실패, 모든 지원 값 형식, 포함된 두 커서 파일을 검증합니다. 현재 사용자의 레지스트리나 실제 커서를 바꾸는 통합 검사는 자동으로 수행하지 않습니다.
