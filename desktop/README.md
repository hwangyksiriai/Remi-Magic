# 레미의 바탕화면 마법

브라우저 확장은 웹 페이지 안에서만 동작하므로, Windows 바탕화면 등장은 별도 Electron 앱으로 실행합니다.

```powershell
npm install
npm run desktop
```

시작하면 설정 창과 시스템 트레이 아이콘이 나타납니다. 설정 창의 **지금 산책하기**, **다섯 명 함께 마법**, **선택한 친구 변신**으로 바로 확인할 수 있습니다. 창을 닫으면 트레이에 남습니다. **완전히 종료** 또는 트레이의 **종료**로 끝낼 수 있습니다.

- 기본 자동 등장 간격: 이전 등장 종료 후 60~180초, 등장 시간: 약 20초.
- 다섯 캐릭터 중 무작위 또는 원하는 캐릭터 선택. 단체 마법에는 다섯 명 모두 등장합니다.
- 산책은 사용자가 제공한 평상복 원본 PNG 전체가 화면 아래쪽을 이동하며 살짝 오르내리는 표현입니다. 팔·다리를 새로 그리거나 그림을 좌우 반전하지 않습니다. 단체 장면은 제공된 변신 후 PNG로 모이기 → 빛과 마법 → 흩어지기 순서입니다.
- 변신은 약 10초입니다. 주문과 빛 속에서 변신 전·후 그림 전체가 자연스럽게 전환됩니다. 변신 중 리듬탭과 단계 안내 글씨는 표시하지 않습니다.
- 원본 PNG의 가로세로 비율과 그림을 유지합니다. 보관 원본 10장은 그대로 두고, 장메이·유사랑·진보라·나모모의 변신 후 그림은 별도의 투명 배경 추출본으로 표시합니다. 표시용 추출본도 원본 해상도와 RGB 색상을 유지합니다.
- 마우스가 있는 모니터의 작업 영역에서 나타나므로 작업 표시줄을 침범하지 않습니다. 모니터 추가·제거·크기 변경을 반영합니다.
- 투명한 클릭 통과 창이며 앱 위에 표시됩니다. Windows의 바탕화면 배경 레이어에 끼워 넣는 방식은 아닙니다.
- 자동 등장, 빈도, 캐릭터, 음성 언어, 소리, 음량, 움직임 줄이기 설정은 Electron 사용자 데이터 폴더의 `companion-settings.json`에 저장됩니다.
- 기본 소리는 꺼져 있습니다. 활성화하면 변신·단체 마법 때 효과음과 포함된 한국어/일본어 원본 발췌를 재생합니다. 변신 주문은 시작 약 1.2초 후에 들어갑니다. **다른 언어 원음 허용**을 켰을 때만 선택한 언어가 없는 캐릭터의 다른 언어 녹음으로 대체하고 실제 언어를 안내합니다. 끄면 해당 언어 녹음이 없는 캐릭터는 주문 없이 효과음만 재생합니다. 성우 음색을 합성한 음성이 아닙니다.
- Windows의 움직임 줄이기 환경 설정도 반영합니다. 잠금·절전 중에는 등장과 음성을 취소합니다. Windows 시작 프로그램 등록은 하지 않습니다.

캐릭터는 사용자가 직접 제공한 변신 전·후 원본 이미지 10장을 바탕으로 표시합니다. 사용자의 되돌리기 요청에 따라 부위별 마스크 변신과 확대 연출을 제거하고 두 그림 전체를 주문과 빛으로 잇는 방식으로 복구했습니다. 원본 애니메이션의 연속 프레임이나 몸 회전·착의 동작을 재생하거나 캐릭터 전체를 3D로 복원한 것은 아닙니다. 바탕화면 앱은 브라우저 확장의 캡처 단축키와 별도로 동작하며, 캡처 기능은 확장 안에서 사용합니다.

보안: 렌더러는 `contextIsolation`, `sandbox`를 사용하며 Node 통합을 끕니다. 로컬 파일만 불러오고 외부 네트워크·팝업·탐색·권한 요청을 차단합니다. 제한된 IPC만 노출하며 설정 변경과 종료는 설정 창에서만 허용합니다.

```powershell
node --test tests/desktop-companion.test.mjs
npm run build:desktop
npx electron desktop/main.mjs --smoke-test
```

스케줄 취소, 수동 등장 교체, 자동 등장 일시정지, 잠금/절전, 다섯 캐릭터 선택, 여러 모니터 작업 영역, 전 장면의 화면 경계, 움직임 줄이기를 순수 로직 테스트로 검증합니다. 실제 Windows 투명 합성, 클릭 통과, 음성 언어팩 출력은 실행 환경에서 확인해야 합니다.

`--smoke-test`는 별도 `desktop/artifacts/smoke-profile` 사용자 데이터와 보이지 않는 offscreen 창을 사용합니다. 원본 10장의 빌드 전후 바이트 일치와 이미지 디코딩을 확인한 뒤 실제 Electron 렌더러의 설정 IPC, 격리, 작업 영역, 투명 캔버스, 산책/단체 마법/변신 그림을 확인합니다. `desktop/artifacts/`에 PNG와 JSON 보고서를 쓴 뒤 종료하며 평소 설정은 바꾸지 않습니다. 원본 자체에 있는 배경과 그림 주변의 투명 창 영역은 구분해서 확인합니다.
