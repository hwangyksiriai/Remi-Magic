# Remi Magic · 레미의 마법 커서

**1.2.2** — 사용자가 제공한 다섯 캐릭터의 그림으로 동작하는 Chrome/Edge 확장과 Windows 바탕화면 앱입니다. 원본 PNG 10장은 그대로 보관하고, 흰 배경 제거를 요청한 변신 후 그림 4장은 원본 해상도와 RGB 색상을 유지한 별도 투명 PNG로 표시합니다.

1.2.2에서는 소품의 무거운 투영 그림자를 없애고 따뜻한 분홍빛과 부드러운 반사 조명으로 바꿨습니다. 3D 재질·사선 각도·두께 표현과 마우스에 따른 작은 기울기는 유지합니다.

## 바로 실행

- **바탕화면**: 프로젝트 폴더의 **바탕화면 마법사 실행.cmd** 실행. 트레이에서 설정·숨기기·종료를 선택합니다. 설정 창 닫기는 앱 종료가 아닙니다.
- **브라우저 체험**: npm run dev 후 [로컬 체험](http://127.0.0.1:4173).
- **Chrome/Edge 확장**: 확장 관리 → 개발자 모드 → 압축해제된 확장 로드 → 프로젝트의 dist 폴더. 업데이트 후 확장과 웹페이지를 모두 새로고침합니다.

처음 준비하는 PC는 Node.js 22.12 이상에서 다음 명령을 실행합니다. Electron 설치에는 인터넷 연결이 필요할 수 있습니다.

    npm ci
    npm run check
    npm run dev

## 사용

| 동작 | 결과 |
|---|---|
| 마우스 이동·클릭 | 3D 요술봉, 별빛 궤적과 효과음 |
| 스크롤 | 3D 리듬탭 회전 |
| 빈 공간 0.9초 길게 누르기 | 원본 평상복 → 리듬탭·반짝임 → 빛 속 전환 → 변신 후 모습 → 캡처 |
| Esc / 탭 숨김·포커스 상실 | 진행 중 변신·음성·예정 캡처 취소 |
| 캐릭터·언어 선택 | 도레미·장메이·유사랑·진보라·나모모, 한국어·일본어 |

**다섯 명 모두 리듬탭을 사용합니다.** 변신은 약 10초이며 음성이 더 길면 종료를 기다립니다. 입력창·버튼·링크 위나 드래그 중에는 시작하지 않습니다. 진행 중 캐릭터·언어 변경도 취소합니다.

3D 리듬탭·요술봉은 추가로 제공한 제품 사진을 참고해 투명 커버, 두꺼운 케이스, 금속 테두리와 구슬을 표현합니다. 실제 재질의 광택·반사를 사용한 근사 모델이며 한 장의 사진으로 제조 치수까지 동일하게 복원한 결과는 아닙니다.

두 정지 그림을 빛으로 연결하는 연출입니다. 원작의 중간 동작을 복원하거나 관절·의상 조각을 따로 만들지는 않습니다. 장메이·유사랑·진보라·나모모의 변신 후 그림은 ImageGen으로 얻은 투명도 가이드를 원본 경계에 맞게 다듬고, 원본 RGB에 적용합니다. 얼굴과 색상을 다시 그린 생성 이미지를 표시하지 않습니다. 원본 해상도와 RGB는 유지하지만 알파가 바뀌므로 전체 RGBA가 동일한 사본은 아닙니다. 원래 투명한 도레미와 평상복 5장은 기존 원본을 사용하며, 나모모의 하단 표기도 표시용 파일에 유지합니다. [남은 차이와 이유](IMPLEMENTATION_NOTES.md)를 참고하세요.

확장은 **활성 탭의 보이는 웹페이지**를 캡처합니다. 탭·포커스 검증과 3초 간격 제한이 있으며 브라우저 보호 페이지·OS 전체 화면은 대상이 아닙니다. 체험 페이지는 캐릭터 기념 카드 PNG를 만듭니다.

## 한국어·일본어 음성

사용자가 지정한 원본 영상에서 짧게 발췌한 **7개 음성**을 포함합니다. 약 2~3초이며 원본의 배경음·효과음이 함께 들어 있습니다. 분리된 성우 음성이나 합성 복제 음성이 아닙니다.

| 캐릭터 | 한국어 | 일본어 |
|---|---|---|
| 도레미 | 원본 발췌 포함 | 원본 발췌 포함 |
| 장메이 | 원본 발췌 포함 | 별도 자료 필요 |
| 유사랑 | 원본 발췌 포함 | 원본 발췌 포함 |
| 진보라 | 원본 발췌 포함 | 별도 자료 필요 |
| 나모모 | 별도 자료 필요 | 원본 발췌 포함 |

소리 보관함에서 공통 효과음 3개와 캐릭터별 두 언어 10개 슬롯에 파일을 등록할 수 있습니다. **등록 파일이 기본 발췌를 덮어쓰며, 등록 파일을 지우면 기본 발췌로 돌아갑니다.** 자료가 없는 슬롯을 다른 캐릭터 음성으로 채우지 않습니다. 시스템 시연 음성은 기본 꺼짐이며 선택하면 원본과 구분해 표시합니다.

- 브라우저 지원 MP3/WAV/OGG 등, 파일당 **700 KiB / 15초 이하**.
- 기본 원본 발췌는 변신 시작 후 7초 무렵, 마지막 모습이 드러날 때 재생합니다. 사용자 등록 파일·선택한 시스템 시연은 1.2초에 시작하며, 모두 실제 재생 종료까지 기다린 뒤 캡처합니다.
- 가져온 파일은 브라우저 로컬 저장소에 저장됩니다. 웹 체험과 설치한 확장은 저장소가 다르므로 확장용 파일은 팝업의 **마법 연습실 열기**에서 등록합니다.
- 이전 버전의 도레미·유사랑·장메이 녹음은 한국어 슬롯으로 이어집니다.

원본 링크·발췌 구간·해시는 [음성 출처](assets/voices/attribution.json), 권리 안내는 [에셋 안내](ASSET_NOTICE.md)에 있습니다.

## Windows 바탕화면

npm run desktop 또는 실행 파일로 별도 Electron 앱을 시작합니다. 이전 등장 종료 후 기본 1~3분마다 약 20초 동안 나타납니다. 빈도·일시정지·캐릭터·수동 산책·단체 마법·변신·언어·소리·음량·움직임 줄이기·종료를 제어합니다.

산책은 **평상복 원본 그림 전체가 이동하며 살짝 오르내리는 표현**입니다. 관절을 움직이거나 그림을 반전하지 않습니다. 단체 마법은 도레미의 기존 투명 그림과 나머지 네 명의 배경 추출본에 빛 효과를 더합니다.

마우스가 있는 모니터의 작업 영역에서 클릭 통과 창으로 표시되며 다른 앱 위에도 보일 수 있습니다. 잠금·절전 때 중단하고 Windows 자동 시작은 등록하지 않습니다. 기본 소리는 꺼져 있고 브라우저의 사용자 녹음 보관함은 공유하지 않습니다. [바탕화면 앱 설명](desktop/README.md).

## 개발과 검증

npm run check의 테스트 84개와 브라우저·데스크톱 빌드는 통과했습니다. 실제 소품 렌더에서도 무거운 그림자가 없는 부드러운 조명을 확인했습니다. 네 추출본의 투명 경계·흰 의상·원본 RGB 보존을 검증했고, 다섯 캐릭터의 실제 변신 완료 렌더와 장메이 카드 저장을 확인했습니다. 실제 Windows 렌더러 검증은 npx electron desktop/main.mjs --smoke-test이며 별도 프로필에서 실행 후 종료합니다. 추출 출처와 처리 방식은 [배경 추출 기록](assets/cutout-sources.json)에 기록합니다.
