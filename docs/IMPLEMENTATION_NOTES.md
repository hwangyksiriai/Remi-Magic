# 구현 내역과 남은 차이

2026-09-28 / **1.2.2** 후속 수정

## 현재 결과

|---|---|---|

**변신 중에는 리듬탭과 단계 안내 글씨를 표시하지 않습니다.** 스크롤 때 사용하는 꽃잎 리듬탭은 유지합니다. 이전 버전의 벡터 캐릭터나 새로 그린 의상 조각은 사용하지 않고, 제공된 PNG 전체를 표시합니다. 사용자 원본 PNG 10장은 바이트를 바꾸지 않고 보관하며 화면에는 원본 6장과 별도 배경 추출본 4장을 사용합니다.

## 브라우저 일상 사용 설정

집중 모드에서도 요술봉과 구슬의 자동 움직임은 유지합니다. 소리·궤적·길게 누르기 변신만 실행 시점에 끄고, 마법 모드에 저장한 선택은 보존합니다. 집중 모드에서도 체험 버튼으로 변신을 감상할 수 있습니다. 길게 누르기와 변신 후 캡처는 서로 다른 설정이며, 되돌린 약 10초 변신 자체는 변경하지 않습니다.

클릭 효과음·스크롤 효과음·주문 음성·변신 효과음과 음악을 각각 켜고 끕니다. 전체 소리와 공통 음량도 적용합니다. 한 채널을 끄면 해당 채널의 재생·예정 소리가 중지되며 다른 채널은 유지합니다. 주문 음성에 원래 포함된 배경 음악을 따로 분리한 것은 아닙니다. 즉시 음소거 버튼과 Alt + Shift + M(macOS Option + Shift + M)은 전체 소리를 전환합니다. 집중 모드에서 바꾼 전체 소리 값은 마법 모드로 돌아갈 때 적용됩니다.

확장 팝업의 사이트별 설정은 정확한 호스트 이름을 기준으로 합니다. 같은 호스트의 다른 경로·포트에는 함께 적용하며, 하위 도메인은 별도입니다. 다른 출처의 삽입 프레임도 최상위 탭의 사이트 설정을 따릅니다. 사이트 설정이 확인되지 않으면 확장 커서를 시작하지 않습니다. 웹 체험과 확장의 저장소는 서로 다릅니다.

1·2번 개선은 브라우저 체험과 확장용입니다. 후속 3·4번에서는 브라우저와 Electron 양쪽에 다른 언어 원음 허용 선택을 추가하고, 실제 재생할 언어와 캐릭터별 자료 상태를 안내합니다. 설치 화면과 현재 소스/확장 ZIP 생성도 정리했습니다. 원작과 동일한 새 변신 동작이나 추가 음성 에셋은 포함하지 않습니다. 자세한 범위는 INSTALL.md와 CHARACTER_GUIDE.md를 참고하세요.

## 완전히 같지 않은 부분과 이유

### 변신 동작과 배경

사용자가 부위별 마스크 변신과 확대 연출을 거절하고 이전 상태로 되돌리기를 요청했습니다. 현재는 제공된 변신 전·후 그림 전체를 주문과 빛으로 자연스럽게 잇는 약 10초 연출입니다. 캐릭터를 부위별로 잘라 드러내지 않으며 변신 중 리듬탭과 단계 안내 글씨도 표시하지 않습니다.

연결 자료는 변신 전·후 정지 그림입니다. 영상의 연속 중간 프레임이나 몸 회전·착의 동작을 재생하거나 캐릭터 전체를 3D로 모델링하지 않았으므로 원작과 동일한 안무·입체 움직임이라고 표현하지 않습니다.

최신 요청에 따라 장메이·유사랑·진보라·나모모의 변신 후 그림은 별도 *-transformed-cutout.png를 사용합니다. ImageGen 내장 배경 추출에서 얻은 알파 가이드를 원본 경계에 맞게 다듬은 뒤, 원본 해상도의 RGB에 적용합니다. 생성된 얼굴·의상·색상을 표시하는 방식이 아니므로 원본 그림의 RGB가 유지됩니다. 투명도를 나타내는 알파는 바뀌므로 전체 RGBA가 원본과 픽셀 단위로 같은 사본은 아닙니다. 이미 투명한 도레미 변신 후와 평상복 5장은 바꾸지 않습니다.

보관 원본과 파생본의 연결·알파 처리 방식은 [배경 추출 출처 기록](assets/cutout-sources.json)에 기록합니다. 나모모 원본의 하단 표기는 보관 원본과 최종 표시용 추출본 모두에 유지합니다. 4개 추출본의 투명 경계와 흰 의상을 체크무늬 배경에서 확인했으며 다섯 캐릭터의 실제 변신 완료 렌더도 확인했습니다. 산책은 평상복 그림 전체의 이동과 작은 상하 움직임입니다.

### 사진을 참고한 3D 소품

리듬탭과 요술봉은 추가로 제공된 실제 제품 사진을 참고한 PBR 3D 모델입니다. 리듬탭은 둥근 투명 꽃잎 커버, 두꺼운 분홍 케이스, 금속 테두리, 일곱 색 구슬과 중앙 음악 문양을, 요술봉은 투명 구슬 통과 무지개 손잡이를 반영합니다. 유리·플라스틱·금속의 광택과 반사를 사용하지만 한 장의 사진만으로 실제 제조 치수·보이지 않는 뒷면을 정확히 복원할 수는 없습니다. 참고 사진은 references/에 보존하며 실행 에셋으로 배포하지 않습니다.

1.2.2에서는 무겁게 보이던 소품의 투영 그림자와 그림자 배경판을 제거했습니다. 어두운 반사 환경을 따뜻한 중성 회색으로 바꾸고 분홍빛 보조광을 사용해 더 부드럽게 보이도록 했습니다. 입체 각도·구슬 색상·형상과 재질 구분은 유지합니다. 데스크톱의 2D 리듬탭도 케이스·그림자·구슬 가장자리의 어두운 부분을 완화했습니다.

### 원본 음성

사용자가 지정한 영상에서 짧게 발췌한 **7개 녹음**을 포함했습니다.

| 캐릭터 | 한국어 | 일본어 |
|---|---|---|
| 도레미 | 포함 · 한국어 영상 10~13초 | 포함 · 개별 영상 12~15초 |
| 장메이 | 포함 · 한국어 영상 38~41초 | 별도 자료 없음 |
| 유사랑 | 포함 · 한국어 영상 24~26초 | 포함 · 개별 영상 12~15초 |
| 진보라 | 포함 · 한국어 영상 52~54초 | 별도 자료 없음 |
| 나모모 | 별도 자료 없음 | 포함 · 개별 영상 11~14초 |

출처는 [한국어 영상](https://www.youtube.com/watch?v=ulQqVjIT0-c), 일본어 [도레미](https://www.youtube.com/watch?v=Nd_sv-li7nY)·[유사랑](https://www.youtube.com/watch?v=576vUL2A_2w)·[나모모](https://www.youtube.com/watch?v=KdUtVDHts2g)입니다. 실제 파일 길이·출처·SHA256은 [음성 출처 기록](assets/voices/attribution.json)에 있습니다.

발췌는 속도·음높이를 바꾸지 않은 짧은 MP3이며 원본의 음악·효과음이 함께 들어 있습니다. 성우 음성만 분리하거나 음색을 합성한 것이 아닙니다. 전체 영상이나 노래를 넣지 않았고 재생 때 유튜브에 접속하지 않습니다. **실제 사람이 들어 원본 성우 음색과 대사를 대조하는 청취 검증은 완료했다고 주장하지 않습니다.**

장메이·진보라에 지정된 일본어 링크가 유사랑 링크와 같아 두 캐릭터의 별도 음성을 확보한 것으로 처리하지 않았습니다. 제공된 한국어 영상에서 나모모 구간도 따로 확인하지 못했습니다. 없는 슬롯은 다른 캐릭터 목소리로 채우지 않으며, 시스템 시연은 기본 꺼짐입니다. 사용자가 선택하면 원본이 아닌 시스템 음성으로 구분됩니다.

소리 보관함에 가져온 파일이 기본 발췌보다 우선하며, 가져온 파일을 지우면 기본 발췌로 돌아갑니다. 사용자 파일은 브라우저 지원 MP3/WAV/OGG 등, 700 KiB·15초 이하입니다. 브라우저 로컬 저장소에 보관하며 웹 체험과 설치한 확장의 저장소는 다릅니다.

기본 발췌·사용자 등록 음성·선택한 시스템 시연은 변신 시작 약 1.2초 후에 시작합니다. 첫 클릭에서 AudioContext를 열고 음성 디코딩을 기다린 뒤 연출을 시작합니다. 나모모 한국어는 같은 캐릭터의 일본어 원음, 장메이·진보라 일본어는 각각 같은 캐릭터의 한국어 원음으로 대체하며 설정 화면에 실제 언어를 표시합니다. 원하는 언어의 사용자 녹음이 있으면 우선합니다. 캡처는 실제 음성 종료를 기다립니다.

요술봉은 마우스를 멈춘 뒤에도 애니메이션 프레임을 유지합니다. 위쪽 구슬은 계속 회전·상하 운동하고 손잡이 구슬은 내부에서 이동·회전합니다. 구슬 경계와 무지개 순서를 유지하며, 움직임 줄이기 환경 설정에서는 자동 움직임을 줄입니다.

원음의 약 1.2초 진입과 같은 캐릭터의 다른 언어 대체 동작은 복구한 변신에서도 유지합니다. 오디오 출력 신호 검사는 스피커를 통한 실제 청취를 대신하지 않습니다.

### 바탕화면과 캡처 범위

브라우저 확장은 OS 바탕화면에 창을 만들 수 없어 별도 Electron 앱으로 제공합니다. 마우스가 있는 모니터의 작업 영역에서 이동하고 다른 앱 위에도 보일 수 있습니다. Windows 배경 전용 레이어나 다른 창의 모서리를 인식하는 기능은 아닙니다.

기본 등장 간격은 이전 등장 종료 후 1~3분, 등장 시간은 약 20초입니다. 설정 창·트레이에서 수동 실행·빈도·일시정지·숨기기·종료를 제어합니다. 기본 소리는 꺼져 있고 Windows 자동 시작은 등록하지 않습니다. 데스크톱은 브라우저의 사용자 녹음 보관함을 공유하지 않습니다.

확장은 활성 탭의 보이는 영역만 PNG로 저장하며 OS 전체 화면을 캡처하지 않습니다. 체험 페이지는 기념 카드를 만듭니다. 변신은 약 10초 뒤 완성 이미지를 유지하고, 음성이 길면 종료를 기다립니다. Esc·탭 숨김·포커스 상실·캐릭터나 언어 변경 시 취소합니다.

## 실행과 검증

프로젝트 폴더: 저장소를 복제한 Remi-Magic 루트

- 바탕화면: **바탕화면 마법사 실행.cmd** 또는 npm run desktop. 창을 닫아도 트레이에 남으므로 **완전히 종료**를 사용합니다.
- 체험: npm run dev 후 [로컬 체험](http://127.0.0.1:4173).
- 확장: Chrome/Edge 확장 관리에서 dist 로드. 업데이트 후 확장·웹페이지를 새로고침합니다.
- 개발: Node.js 22.12 이상, 처음은 npm ci, 변경 후 npm run check.

변경 후 npm run check와 함께 다섯 캐릭터의 두 그림 전환, 완성 원본 전체, 음성 종료와 캡처 순서, 움직임 줄이기 설정을 확인합니다. 실행하지 않은 검사를 통과한 것으로 기록하지 않습니다.

실제 설치한 확장의 화면 PNG 다운로드, 물리 마우스 클릭 통과, 실제 스피커 출력·원본 음색 비교, macOS는 별도 실행 환경에서 확인해야 합니다. 이번 소스 변경은 GitHub에 게시하지 않았으며 공개 사이트의 docs/ 번들은 별도 갱신·배포가 필요합니다.

## Windows 간편 적용 앱 (1.3.1)

다운로드한 EXE를 열고 적용 버튼을 누르면 Windows 기본 일반 선택·링크 선택 포인터에 움직이는 요술봉을 지정합니다. 기존 커서 파일 2종을 내장하며 임의의 새 에셋을 생성하지 않습니다. 사용자별 보관 폴더와 원래 설정 백업으로 적용·크기 변경·복구를 처리합니다. Node.js, 인터넷, 자동 시작, 관리자 권한을 요구하지 않습니다. 소리·잔상·변신은 이 네이티브 커서 파일에 포함되지 않습니다. Win10/11용 자체 제작 미서명 EXE이며 Windows 보안 확인이 표시될 수 있습니다. 사용자의 실제 포인터를 자동 변경하지 않고 격리된 테스트와 Windows 커서 로더로 검사합니다.
