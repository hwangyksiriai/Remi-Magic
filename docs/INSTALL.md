# Remi Magic 1.3.1 · 설치와 종료 안내

## 1. 기존 Windows 요술봉 ZIP 적용

1. `remi-magic-windows-cursors.zip`을 다운로드해 계속 보관할 폴더에 압축을 풉니다.
2. Windows 키 + R → `main.cpl` → Enter를 누릅니다.
3. **포인터 → 일반 선택 → 찾아보기**에서 `Remi-Wand-Large.ani`를 선택하고 **적용**합니다. 링크 위에서도 유지하려면 **연결 선택**에도 같은 파일을 지정합니다.

ANI는 움직이는 구슬, CUR는 정지 커서입니다. 적용 후 파일을 옮기거나 삭제하지 마세요. 원래대로 돌아가려면 이전 Windows 포인터 구성표를 선택합니다. 실제 크기는 Windows 포인터 크기 설정을 따릅니다.

## 2. Windows 간편 적용 EXE — 선택 사항

1. **Remi-Magic-Setup.exe**를 다운로드합니다.
2. 받은 파일을 **두 번 클릭**합니다.
3. **요술봉 적용하기**를 누릅니다.

끝입니다. 압축 풀기, 명령어 입력, Node.js 설치, 관리자 권한은 필요하지 않습니다. 필요한 요술봉 파일은 앱이 개인 폴더에 보관하므로 받은 EXE를 옮겨도 적용된 커서는 유지됩니다. 앱을 닫아도 요술봉은 계속 사용됩니다.

**되돌리기:** 같은 EXE를 열고 **원래 마우스로 돌리기**를 누릅니다. 처음 적용하기 전의 일반 선택·링크 선택 커서 설정을 보관했다가 복구합니다. 다시 적용해도 처음 설정은 덮어쓰지 않습니다. 적용한 적이 없으면 복구를 눌러도 현재 설정을 바꾸지 않습니다.

**기능:** 바탕화면과 Windows 기본 포인터를 따르는 프로그램에서 요술봉과 구슬 반복 애니메이션을 표시합니다. 실제 표시 크기는 Windows 포인터 크기 설정을 따릅니다. 글자 선택·창 크기 조절 포인터는 기존 설정을 유지합니다. 소리·잔상·길게 누르기 변신은 브라우저용 기능입니다. macOS에서는 이 EXE를 사용할 수 없습니다.

이 파일은 자체 제작한 서명되지 않은 프로그램이므로 Windows나 브라우저에서 보안 확인이 표시될 수 있습니다. 보안 설정을 해제할 필요는 없습니다. 자동 시작이나 인터넷 연결을 사용하지 않습니다.

## 3. 웹에서 체험

웹 체험은 열린 페이지 안에서만 동작합니다. 프로그램 설치는 필요하지 않습니다. **마법 커서**를 켜서 사용하고, 끄거나 탭을 닫으면 끝납니다. 웹 체험의 캡처는 캐릭터 PNG 카드입니다. 다른 사이트의 실제 화면 캡처는 확장 프로그램에서 사용합니다.

직접 내려받은 소스로 체험하려면 Node.js 22.12 이상을 설치한 뒤 프로젝트 폴더에서 `npm ci`, `npm run build`, `npm run dev`를 실행하고 표시된 로컬 주소를 엽니다. 웹 체험과 설치한 확장의 설정·음성 저장소는 별개입니다.

## 4. 다른 사이트에서 사용

1. `remi-magic-extension.zip`을 압축 해제합니다. 설치에 Node.js는 필요하지 않습니다.
2. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`를 엽니다.
3. **개발자 모드 → 압축해제된 확장 프로그램 로드**에서 `manifest.json`이 있는 폴더를 선택합니다.
4. 사용할 웹페이지를 새로고침하고, 확장 아이콘을 눌러 **마법 커서**와 **이 사이트에서 사용**을 켭니다.

일반 HTTP/HTTPS 페이지에서 동작합니다. 브라우저 설정·새 탭·확장 스토어 등 보호된 화면에는 표시되지 않습니다. 로컬 파일은 확장 관리의 **파일 URL에 대한 액세스 허용**이 별도로 필요합니다. macOS도 같은 확장 ZIP을 사용하도록 만들었지만 실기기 검증은 하지 않았습니다.

**끄기:** 팝업의 전체 커서 또는 현재 사이트 스위치를 끕니다. 소리만 끄려면 Windows `Alt + Shift + M`, Mac `Option + Shift + M`을 누릅니다. 집중 모드에서는 소리·잔상·길게 누르기 변신이 쉬고, 큰 요술봉과 구슬은 남습니다.

**업데이트:** 새 ZIP을 기존 확장 폴더에 압축 해제한 뒤 확장 관리에서 새로고침하고 웹페이지도 새로고침합니다. 폴더 위치를 유지하면 같은 확장으로 설정을 이어 사용할 수 있습니다.

**삭제:** 확장 관리에서 **삭제**를 누른 뒤 내려받은 폴더를 지웁니다. 필요한 사용자 녹음 원본 파일과 저장한 PNG는 먼저 별도로 보관합니다.

## 5. 캐릭터 산책 앱·개발자용 소스

`remi-magic-source.zip`에는 다섯 캐릭터가 산책·변신하는 별도 Electron 앱의 소스가 들어 있습니다. 완성된 EXE 설치 파일이나 Windows 시스템 마우스 커서 패키지가 아닙니다.

1. ZIP을 한 폴더에 압축 해제합니다.
2. Node.js 22.12 이상을 준비합니다. 최초 의존성 다운로드에는 인터넷 연결이 필요합니다.
3. **바탕화면 마법사 실행.cmd**를 실행하거나 프로젝트 폴더의 터미널에서 `npm ci` 후 `npm run desktop`을 실행합니다.
4. 설정 창에서 캐릭터·등장 빈도·소리·언어를 선택합니다. 브라우저의 집중 모드와 설정은 공유하지 않습니다.

**잠시 쉬기:** 설정의 자동 등장을 끄거나 **지금 숨기기**를 누릅니다. **완전히 종료** 또는 트레이 메뉴의 **종료**로 앱을 끝냅니다. 설정 창의 X만 누르면 트레이에서 계속 실행됩니다.

**삭제:** 완전히 종료한 뒤 압축을 푼 폴더를 삭제합니다. 개인 설정까지 지우려면 Windows `%APPDATA%\Remi Magic Desktop\companion-settings.json`을 삭제합니다. 시작 프로그램이나 시스템 커서 설정은 이 앱이 변경하지 않습니다.

## 확인된 범위

| 경로 | Windows | macOS |
|---|---|---|
| 요술봉 간편 적용 EXE | 현재 Windows에서 실제 설정 적용·새로고침 확인. 복구 로직은 격리된 자동 검사 | 지원하지 않음 |
| 웹 체험 | 현재 Windows의 Chromium 미리보기에서 화면·설정 확인 | 실기기 미검증 |
| Chrome/Edge 확장 | 빌드·설정/캡처 로직 검사 완료, 실제 확장 설치·캡처는 별도 확인 필요 | 같은 확장 ZIP 대상, 실기기 미검증 |
| Electron 바탕화면 캐릭터 | Windows 소스 실행용, 빌드·로직 검사 완료, 이번 버전 실제 앱 실행은 미검증 | 설치 패키지 제공하지 않음 |

## 다운로드 파일

- **`remi-magic-windows-cursors.zip`: 기존 움직이는 요술봉·리듬탭 ANI/CUR와 사용방법.**
- `Remi-Magic-Setup.exe`: 같은 요술봉을 적용·복구하는 선택용 Windows 앱.
- `remi-magic-extension.zip`: 설치 가능한 확장 폴더. 안의 `downloads/remi-magic-source.zip`은 전체 소스입니다.
- `remi-magic-source.zip`: 의존성·개인 설정을 제외한 프로젝트 소스입니다. `npm ci`로 의존성을 준비합니다.
- `SHA256SUMS.txt`: 배포 파일의 무결성을 확인할 해시입니다.

Windows에서 `npm run build`를 실행하면 간편 적용 EXE와 기존 커서·확장·소스 ZIP을 `dist/downloads/`에 만듭니다. Windows 간편 적용 앱만 만들 때는 `npm run build:windows`를 사용합니다. 그 밖의 환경에서는 브라우저용 파일과 ZIP을 만들 수 있으며 EXE 컴파일은 Windows가 필요합니다. `npm run build:pages`는 공개 사이트용 `docs/`를 준비하며, 그 명령 자체로 GitHub에 게시하지는 않습니다. 캐릭터·음성의 사용 범위는 `ASSET_NOTICE.md`, 캐릭터별 자료는 `CHARACTER_GUIDE.md`를 확인하세요.
