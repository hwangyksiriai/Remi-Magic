기존 요술봉 커서를 직접 적용해요

기존 요술봉 ZIP 받기 ↓

움직이는 큰 요술봉으로 바꾸기

  1. ZIP을 받고 압축을 풀어요. 적용한 뒤에도 폴더를 옮기거나 지우지 마세요.
  2. Windows 키 + R을 누르고 main.cpl을 입력한 뒤 Enter를 눌러요.
  3. 포인터 → 일반 선택 → 찾아보기에서 Remi-Wand-Large.ani를 선택하고 열기 → 적용을 누르세요.

파일 유형이 ‘애니메이션’이면 움직이는 구슬, ‘커서’이면 고정된 그림이에요. Large는 큰 버전, Regular는 기본 버전이에요.

링크 위에서도 사용·되돌리기

링크 위에서도 요술봉을 쓰려면 연결 선택에도 같은 파일을 지정하세요.

Windows 기본 마우스로 돌아가려면 같은 포인터 탭의 구성표에서 Windows 기본값을 고르고 적용을 누르세요.

기존에 쓰던 다른 커서를 남겨두려면 변경 전에 ‘다른 이름으로 저장’으로 구성표를 저장해 주세요.

Windows의 마우스 모양을 바꾸는 파일이에요. 소리·잔상·클릭 변신은 브라우저 확장에서 사용할 수 있어요.

  1. 같은 파일을 다시 두 번 클릭해요.

처음 적용하기 전의 마우스 설정으로 돌아가요. 적용 파일은 찾기 쉬운 곳에 보관해 주세요.

Windows 전용이에요. Mac에서는 웹 체험을 이용해 주세요. 직접 만든 앱이라 Windows가 처음 열 때 보안 확인 화면을 표시할 수 있어요.

확장 ZIP 받기 ↓

설치하기

  1. 확장 ZIP을 다운로드하고 압축을 풀어요.
  2. Chrome 주소창에 chrome://extensions, Edge에서는 edge://extensions를 입력해요.
  3. 개발자 모드를 켜고 압축해제된 확장 프로그램 로드를 선택해요.
  4. manifest.json이 들어 있는 폴더를 선택해요. 이미 열려 있던 웹페이지는 새로고침하세요.

끄기·삭제하기

브라우저의 확장 아이콘에서 마법 커서를 끄세요. 특정 사이트만 쉬려면 이 사이트에서 사용을 끄면 돼요.

완전히 삭제하려면 확장 프로그램 관리 화면에서 Remi Magic → 삭제를 선택하세요.

브라우저 설정·확장 스토어 등 보호된 화면에는 표시되지 않아요. 확장을 설치하면 실제 웹페이지 캡처를 사용할 수 있어요.

Windows·macOS의 Chrome/Edge를 대상으로 만들었어요. 실제 확장 설치 환경과 macOS 기기에서는 아직 확인하지 못했어요.

캐릭터 산책 앱을 직접 실행해요

전체 소스 ZIP 받기 ↓

준비·실행하기

  1. 전체 소스 ZIP을 풀고 Node.js 22.12 이상을 설치하세요.
  2. 압축을 푼 프로젝트 폴더에서 터미널을 열고 npm ci를 실행해요.
  3. 바탕화면 마법사 실행.cmd를 열거나 터미널에서 npm run desktop을 실행해요.

설치형 EXE가 아닌 소스 파일이에요. 처음 실행할 때는 인터넷 연결이 필요해요.

일시정지·종료·삭제하기

알림 영역의 앱 아이콘에서 일시정지나 종료를 선택해요. 설정 창만 닫으면 앱은 계속 실행돼요.

삭제할 때는 먼저 앱을 완전히 종료한 뒤 압축을 푼 프로젝트 폴더를 지우세요.

이 앱은 캐릭터가 등장하는 바탕화면 동반자예요. 브라우저 요술봉 설정과 별도로 동작하며, 시스템 커서 변경 기능은 포함하지 않아요.

Windows용 소스 실행 경로를 제공해요. 실제 데스크톱 표시·클릭 통과는 실기기 미검증이며, macOS용 바탕화면 앱은 제공하지 않아요.

이번 변신 연출에 관해

캐릭터는 보내주신 변신 전·후 그림을 사용하고, 변신 후 그림의 흰 배경은 투명하게 분리했어요. 주문과 빛으로 두 그림을 자연스럽게 이어줘요. 원작의 연속 변신 프레임과 몸 회전, 옷을 입는 동작을 재현한 것은 아니에요. 참고 영상의 짧은 변신 대사 7개를 사용하며 배경음도 함께 들려요. 다른 언어 원음 허용을 켜면 나모모 한국어, 장메이·진보라 일본어가 없을 때 같은 캐릭터의 다른 언어 녹음을 사용해요.
