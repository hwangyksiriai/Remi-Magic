# 캐릭터와 음성 안내 · 1.3.0

| 캐릭터 | 평상복 원본 해상도 | 변신 표시 이미지 해상도 | 한국어 녹음 | 일본어 녹음 |
|---|---|---|---|---|
| 도레미 | 288 × 638 | 1000 × 1534 | 있음 | 있음 |
| 장메이 | 203 × 614 | 282 × 587 | 있음 | 없음 |
| 유사랑 | 232 × 630 | 316 × 453 | 있음 | 있음 |
| 진보라 | 221 × 631 | 260 × 470 | 있음 | 없음 |
| 나모모 | 230 × 638 | 420 × 400 | 없음 | 있음 |

원본 그림 10장의 SHA256과 포함 녹음 7개의 SHA256을 출처 기록과 대조했습니다. 도레미의 변신 후 원화는 원래 투명한 파일이고, 나머지 네 명은 원본 해상도·RGB를 유지한 별도 배경 추출본을 표시합니다. 원본은 보관합니다. 이 점검은 자료 연결과 파일 보존 검사이며, 성우 음색을 원작과 직접 청취 비교한 검사는 아닙니다.

## 표시 크기와 소품

다섯 명 모두 그림 전체를 원래 비율과 공통 하단 기준선에 맞춥니다. 가로로 넓은 나모모 그림은 같은 영역에 온전히 들어가도록 다른 그림보다 낮게 보일 수 있습니다. 얼굴이나 신체를 따로 확대하거나 그림을 잘라서 크기를 맞추지 않습니다. 원본의 낮은 해상도는 새 고해상도 원화를 확보해야 개선할 수 있습니다.

요술봉과 리듬탭은 다섯 캐릭터가 사용하는 **공통 모델**입니다. 캐릭터 선택은 그림, 장면의 색, 연결된 주문 녹음을 바꿉니다. 캐릭터마다 또는 작품 시즌마다 소품을 완전히 고증한 구성으로 표시하지 않습니다. 원화·소품의 시즌을 확인할 별도 자료도 현재 없습니다.

## 주문 언어 선택

**다른 언어 원음 허용**을 켜면 선택한 언어의 녹음이 없을 때 같은 캐릭터의 다른 언어 녹음을 사용합니다. 끄면 다른 언어를 자동 재생하지 않습니다. 현재 선택과 실제 사용할 언어를 변신 전에 안내합니다. 이전 사용자 설정은 기본 허용으로 이어집니다.

사용자가 등록한 해당 언어 녹음이 우선입니다. 브라우저에서 **시스템 시연 음성**을 별도로 켠 경우, 녹음이 없어도 선택한 언어의 설치된 시스템 음성을 사용할 수 있습니다. 시스템 음성은 원본 성우 음성이 아닙니다. 집중 모드·전체 음소거·주문 음성 끄기는 이 설정보다 우선합니다. Electron 바탕화면 앱도 다른 언어 허용을 선택할 수 있지만 브라우저 설정과는 별개로 저장됩니다.

포함된 녹음은 참고 영상의 짧은 2~3초 구간으로 배경 음악과 효과음도 들어 있습니다. **변신 효과음·음악**을 꺼도 주문 녹음 안의 배경음을 따로 제거하지는 못합니다.

## 변신 표현

사용자가 되돌리기를 요청한 약 10초의 전체 그림 전환을 유지합니다. 주문 음성은 시작 약 1.2초 후에 들어갑니다. 부위별 마스크나 임의의 중간 의상은 다시 추가하지 않았습니다. 원작과 같은 연속 착의·회전 동작을 만들려면 해당 동작의 프레임 또는 검증 가능한 애니메이션 자료를 먼저 확보해야 합니다.
