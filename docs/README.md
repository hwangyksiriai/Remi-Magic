# Remi Magic · 레미의 마법 커서

**1.3.1** — Windows 요술봉 간편 적용 앱, Chrome/Edge 확장과 캐릭터 산책 앱입니다. 원본 PNG 10장은 그대로 보관하고, 흰 배경 제거를 요청한 변신 후 그림 4장은 원본 해상도와 RGB 색상을 유지한 별도 투명 PNG로 표시합니다.

**[공개 체험·다운로드](https://hwangyksiriai.github.io/Remi-Magic/)** · **[기존 요술봉 ZIP 받기](https://hwangyksiriai.github.io/Remi-Magic/downloads/remi-magic-windows-cursors.zip)**

Windows 바탕화면에서는 기존 ANI/CUR ZIP을 사용합니다. `Remi-Magic-Setup.exe`로 같은 요술봉을 적용·복구하는 방법도 선택할 수 있습니다. Windows 커서 파일은 요술봉 모양·구슬 애니메이션용이며 브라우저의 소리·잔상·변신과는 별개입니다.

1.3.0은 별빛 보석 클릭점·집중 모드·소리별 설정에 더해 **다른 언어 원음 허용**을 선택하고 실제 재생할 언어를 미리 확인할 수 있습니다. 첫 화면에서 웹 체험, 확장 설치, Windows 바탕화면 소스 실행을 구분합니다. [설치·끄기·삭제 안내](INSTALL.md), [캐릭터별 자료와 음성 안내](CHARACTER_GUIDE.md)를 확인하세요.

1.2.2에서는 소품의 무거운 투영 그림자를 없애고 따뜻한 분홍빛과 부드러운 반사 조명으로 바꿨습니다. 3D 재질·사선 각도·두께 표현과 마우스에 따른 작은 기울기는 유지합니다. 2026-09-28 후속 수정에서는 주문 음성 재생과 정지 커서의 지속 구슬 운동을 보완했습니다. 사용자의 되돌리기 요청에 따라 변신은 기존 두 그림을 주문과 빛으로 잇는 방식으로 복구했습니다.

## 바로 실행

- **바탕화면 마우스**: 기존 커서 ZIP 압축 해제 → Windows 키 + R → `main.cpl` → 포인터 → 일반 선택 → 찾아보기 → `Remi-Wand-Large.ani` → 적용. 자세한 방법과 선택용 EXE는 [설치 안내](INSTALL.md)에 있습니다.
- **캐릭터 산책 앱(개발자용)**: 프로젝트 폴더의 **바탕화면 마법사 실행.cmd** 실행. 트레이에서 설정·숨기기·종료를 선택합니다. 설정 창 닫기는 앱 종료가 아닙니다.
- **브라우저 체험**: npm run dev 후 [로컬 체험](http://127.0.0.1:4173).
- **Chrome/Edge 확장**: 확장 관리 → 개발자 모드 → 압축해제된 확장 로드 → 프로젝트의 dist 폴더. 업데이트 후 확장과 웹페이지를 모두 새로고침합니다.

아래는 **소스를 직접 개발하거나 캐릭터 산책 앱을 실행할 때만** 필요한 준비입니다. Node.js 22.12 이상에서 다음 명령을 실행합니다. Electron 설치에는 인터넷 연결이 필요할 수 있습니다.

    npm ci
    npm run check
    npm run dev

## 사용

| 동작 | 결과 |
|---|---|
| 마우스 이동·클릭 | 3D 요술봉, 별빛 궤적과 효과음 |
| 스크롤 | 3D 리듬탭 회전 |
| 빈 공간 0.9초 길게 누르기 | 주문·빛 → 변신 후 모습 → 완성 포즈 → 캡처 |
| Alt + Shift + M / macOS Option + Shift + M | 전체 소리 켜기·끄기 |
| Esc / 탭 숨김·포커스 상실 | 진행 중 변신·음성·예정 캡처 취소 |
| 캐릭터·언어 선택 | 도레미·장메이·유사랑·진보라·나모모, 한국어·일본어 |

**변신 중에는 리듬탭과 단계 안내 글씨를 표시하지 않습니다.** 변신은 약 10초이며 음성이 더 길면 종료를 기다립니다. 입력창·버튼·링크 위나 드래그 중에는 시작하지 않습니다. 진행 중 캐릭터·언어 변경도 취소합니다.

3D 리듬탭·요술봉은 추가로 제공한 제품 사진을 참고해 투명 커버, 두꺼운 케이스, 금속 테두리와 구슬을 표현합니다. 실제 재질의 광택·반사를 사용한 근사 모델이며 한 장의 사진으로 제조 치수까지 동일하게 복원한 결과는 아닙니다.

마우스를 멈춰도 요술봉의 구슬은 계속 회전·상하 운동하며 손잡이 내부에서도 움직입니다. 움직임 줄이기 설정에서는 자동 움직임을 줄입니다.

변신은 제공된 변신 전·후 그림 전체를 주문과 빛으로 자연스럽게 이어주는 연출입니다. 원본의 비율과 그림을 유지하며 부위별로 잘라 움직이지 않습니다. 원작의 연속 변신 프레임이나 몸 회전·착의 동작을 복원하거나 캐릭터 전체를 3D로 만든 결과는 아닙니다.

장메이·유사랑·진보라·나모모의 변신 후 그림은 ImageGen으로 얻은 투명도 가이드를 원본 경계에 맞게 다듬고, 원본 RGB에 적용합니다. 얼굴과 색상을 다시 그린 생성 이미지를 표시하지 않습니다. 원본 해상도와 RGB는 유지하지만 알파가 바뀌므로 전체 RGBA가 동일한 사본은 아닙니다. 원래 투명한 도레미와 평상복 5장은 기존 원본을 사용하며, 나모모의 하단 표기도 표시용 파일에 유지합니다. [남은 차이와 이유](IMPLEMENTATION_NOTES.md)를 참고하세요.

확장은 **활성 탭의 보이는 웹페이지**를 캡처합니다. 탭·포커스 검증과 3초 간격 제한이 있으며 브라우저 보호 페이지·OS 전체 화면은 대상이 아닙니다. 체험 페이지는 캐릭터 기념 카드 PNG를 만듭니다.

## 일상 사용 설정

다음 설정은 **브라우저 체험과 Chrome/Edge 확장**에 적용됩니다. 별도 Electron 바탕화면 앱은 자체 설정을 사용합니다.

- **클릭 위치와 상태**: 요술봉 끝의 금빛 별 안에 있는 분홍 보석 중심이 실제 클릭 위치입니다. 별은 16px로 고정하고 주변 빛만 은은하게 반짝입니다. 글자 선택·입력, 링크·버튼, 크기 조절은 상자 없이 작은 기호로 표시합니다. 집중 모드와 동작 줄이기 설정에서는 클릭점의 반짝임도 쉽니다.
- **마법 모드 / 집중 모드**: 집중 모드에서도 요술봉과 움직이는 구슬은 유지하며 소리·궤적·길게 누르기 변신을 잠시 끕니다. 마법 모드로 돌아가면 저장한 설정이 복원됩니다. 집중 모드에서도 변신 체험 버튼으로 조용히 감상할 수 있습니다.
- **소리와 주문 음성**: 클릭 효과음, 스크롤 효과음, 주문 음성, 변신 효과음·음악을 각각 켜고 끕니다. 전체 소리와 공통 음량은 네 항목에 함께 적용됩니다. 주문 녹음에 원래 들어 있는 배경음은 주문 음성과 분리되지 않습니다.
- **변신과 캡처**: 길게 눌러 변신하기와 변신 후 캡처는 별도 설정입니다. 캡처를 끄면 변신만 감상합니다. 기존 약 10초 변신 연출은 그대로 유지합니다.
- **이 사이트에서 사용**: 확장 팝업에서 현재 탭의 사이트만 끌 수 있습니다. 호스트 이름이 정확히 같은 사이트에 적용하므로 `example.com`과 `sub.example.com`은 별개입니다. 탭 안에 삽입된 프레임도 최상위 탭의 사이트 설정을 따릅니다.
- **즉시 음소거**: 화면의 음소거 버튼 또는 Alt + Shift + M(macOS는 Option + Shift + M)으로 전체 소리를 전환합니다. 집중 모드에서는 계속 조용하며, 단축키로 바꾼 값은 마법 모드로 돌아갈 때 적용됩니다.

## 한국어·일본어 음성

사용자가 지정한 원본 영상에서 짧게 발췌한 **7개 음성**을 포함합니다. 약 2~3초이며 원본의 배경음·효과음이 함께 들어 있습니다. 분리된 성우 음성이나 합성 복제 음성이 아닙니다.

| 캐릭터 | 한국어 | 일본어 |
|---|---|---|
| 도레미 | 원본 발췌 포함 | 원본 발췌 포함 |
| 장메이 | 원본 발췌 포함 | 별도 자료 필요 |
| 유사랑 | 원본 발췌 포함 | 원본 발췌 포함 |
| 진보라 | 원본 발췌 포함 | 별도 자료 필요 |
| 나모모 | 별도 자료 필요 | 원본 발췌 포함 |

소리 보관함에서 공통 효과음 3개와 캐릭터별 두 언어 10개 슬롯에 파일을 등록할 수 있습니다. **등록 파일이 기본 발췌를 덮어쓰며, 등록 파일을 지우면 기본 발췌로 돌아갑니다.** **다른 언어 원음 허용**을 켰을 때만 선택한 언어가 없는 캐릭터의 다른 언어 녹음을 재생하며 실제 사용할 언어를 미리 표시합니다. 허용 시 나모모 한국어는 나모모 일본어, 장메이·진보라 일본어는 각각 같은 캐릭터의 한국어 원음으로 이어집니다. 다른 캐릭터의 음성은 쓰지 않습니다. 시스템 시연 음성은 기본 꺼짐이며 선택하면 원본과 구분해 표시합니다.

- 브라우저 지원 MP3/WAV/OGG 등, 파일당 **700 KiB / 15초 이하**.
- 기본 원본 발췌·사용자 등록 파일·선택한 시스템 시연은 변신 시작 약 1.2초 후에 시작하며, 모두 실제 재생 종료까지 기다린 뒤 캡처합니다.
- 가져온 파일은 브라우저 로컬 저장소에 저장됩니다. 웹 체험과 설치한 확장은 저장소가 다르므로 확장용 파일은 팝업의 **마법 연습실 열기**에서 등록합니다.
- 이전 버전의 도레미·유사랑·장메이 녹음은 한국어 슬롯으로 이어집니다.

원본 링크·발췌 구간·해시는 [음성 출처](assets/voices/attribution.json), 권리 안내는 [에셋 안내](ASSET_NOTICE.md)에 있습니다.

## Windows 바탕화면

npm run desktop 또는 실행 파일로 별도 Electron 앱을 시작합니다. 이전 등장 종료 후 기본 1~3분마다 약 20초 동안 나타납니다. 빈도·일시정지·캐릭터·수동 산책·단체 마법·변신·언어·소리·음량·움직임 줄이기·종료를 제어합니다.

산책은 **평상복 원본 그림 전체가 이동하며 살짝 오르내리는 표현**입니다. 관절을 움직이거나 그림을 반전하지 않습니다. 단체 마법은 도레미의 기존 투명 그림과 나머지 네 명의 배경 추출본에 빛 효과를 더합니다.

마우스가 있는 모니터의 작업 영역에서 클릭 통과 창으로 표시되며 다른 앱 위에도 보일 수 있습니다. 잠금·절전 때 중단하고 Windows 자동 시작은 등록하지 않습니다. 기본 소리는 꺼져 있고 브라우저의 사용자 녹음 보관함은 공유하지 않습니다. [바탕화면 앱 설명](desktop/README.md).

## 개발과 검증

개발 검증은 npm run check로 테스트와 브라우저·데스크톱 빌드를 실행합니다. 실제 Windows 렌더러 검증은 npx electron desktop/main.mjs --smoke-test이며 별도 프로필에서 실행 후 종료합니다. 추출 출처와 처리 방식은 [배경 추출 기록](assets/cutout-sources.json)에 기록합니다.

기존 ANI/CUR 커서는 저장소와 전체 소스 ZIP의 `desktop-cursors/`, 별도 커서 ZIP에 포함되며 바탕화면 캐릭터 앱과는 별개입니다. [이어 작업하기](HANDOFF.md), [라이선스](LICENSE), [에셋 안내](ASSET_NOTICE.md)를 참고하세요.

`npm run build`는 현재 코드로 기존 커서·확장·소스 ZIP을 `dist/downloads/`에 만듭니다. Windows에서는 간편 적용 EXE도 함께 컴파일합니다. 개인 설정·녹음·node_modules·개발 기록은 포함하지 않습니다. `npm run build:pages`는 동일한 체험 화면과 ZIP을 공개 사이트용 `docs/`에 준비합니다. GitHub 게시와 Pages 배포는 별도입니다. 설치한 확장의 마법 연습실에서도 함께 포함된 소스 ZIP을 받을 수 있습니다.
