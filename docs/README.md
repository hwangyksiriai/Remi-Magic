# Remi Magic · 레미의 마법 커서

Windows·macOS의 Chrome/Edge용 Manifest V3 확장 프로그램과 로컬 체험 화면입니다.

소스 코드와 직접 작성한 문서는 **MIT 라이선스**입니다. 캐릭터 이미지는 MIT 적용 대상에서 제외됩니다. 자세한 범위는 [LICENSE](LICENSE)와 [ASSET_NOTICE.md](ASSET_NOTICE.md)를 확인해 주세요.

## 설치

1. `release/remi-magic-extension.zip`을 압축 해제합니다. 또는 이 프로젝트의 `dist` 폴더를 사용합니다.
2. Chrome에서 `chrome://extensions`, Edge에서 `edge://extensions`를 엽니다.
3. **개발자 모드 → 압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. `manifest.json`이 바로 들어 있는 폴더를 선택합니다.
5. 확장 프로그램 아이콘을 고정하고, 이미 열어 둔 웹페이지를 새로고침합니다.

macOS에서도 같은 절차와 같은 파일을 사용합니다. Node.js는 소스 수정·재빌드 때만 필요하며, 설치만 할 때는 필요하지 않습니다. 이 환경에는 macOS 기기가 없어 macOS 실기기 검증은 하지 못했습니다. Safari, Firefox, OS 바탕화면·다른 앱은 이번 버전의 지원 대상이 아닙니다.

## 사용

| 동작 | 결과 |
|---|---|
| 마우스 이동 | 기본 160px 3D 요술봉으로 커서를 시각적으로 대체. 14개의 7색 구슬, 별·음표·무지개 궤적 |
| 짧게 왼쪽 클릭 | 마법 입자와 벨 효과음 |
| 위·아래 스크롤 | 사진을 참고한 꽃잎형 3D 리듬탭으로 전환, 방향에 따른 회전과 소리 |
| 빈 공간을 0.9초 길게 누름 | 리듬탭 발광 → 선택한 캐릭터 등장 → 마지막 포즈에서 PNG 캡처 요청 |
| Esc | 변신 중지 |
| 확장 아이콘 | 크기 100–240px, 소리, 음량, 궤적, 변신 캡처, 누르는 시간, 캐릭터 선택 |

드래그하거나 입력창·버튼·링크 위에서 길게 누르면 변신하지 않습니다. 원래 사이트의 클릭·스크롤은 가로채지 않습니다. 음성 자동재생 제한 때문에 각 페이지에서 처음 클릭/키 입력을 한 뒤 스크롤 소리가 활성화됩니다.

## 캡처

확장 프로그램은 **현재 활성 웹페이지의 보이는 영역**을 PNG로 저장합니다. 전체 스크롤 페이지, 브라우저 바깥, 화면 녹화는 아닙니다. 마법 연출도 화면에 포함됩니다. 저장 위치 선택창이 열리며 기본 이름은 `Remi-Magic/remi-날짜.png`입니다.

현재 탭·창의 포커스를 확인하고, 캡처 중 탭 전환/이동이 감지되면 이미지를 버립니다. 3초 간격 제한이 있으며 한 번 누르기에 한 번만 캡처합니다. 캡처 이미지는 외부에 전송하지 않습니다.

**체험 화면은 웹페이지 캡처 대신 선택한 캐릭터의 장식 카드를 저장합니다.** 실제 웹페이지 캡처를 쓰려면 확장을 설치해야 합니다. 삽입된 iframe 안의 변신은 캡처하지 않으므로 페이지 본문에서 시작해 주세요.

## 소리 보관함

확장 팝업의 **마법 연습실 열기 → 소리 보관함**에서 파일을 연결합니다.

- 공통: 클릭 효과음, 리듬탭 회전, 변신 음악
- 캐릭터별: 레미, 사랑이, 메이 주문 목소리
- MP3/WAV/OGG 등 브라우저가 해독하는 오디오, 파일당 700 KB / 15초 이하
- 주문 목소리는 리듬탭 발광 뒤 1.2초 시점에 재생하며, 그 길이에 맞춰 마지막 캡처를 기다립니다.
- 등록한 오디오는 브라우저 로컬 저장소에만 저장됩니다. 로컬 웹 체험과 설치된 확장 프로그램은 저장소가 다르므로, 확장에서 사용하려면 확장 팝업을 통해 연습실을 여세요.

기본 제공되는 소리는 직접 합성한 벨 효과음입니다. 원본 성우 음성·음악 파일은 포함되지 않습니다. 자동 자막의 주문 인식 오류 때문에 대사를 임의로 확정하거나 합성하지 않았습니다.

## 고증 및 현재 한계

- 리듬탭: 사용자 제공 사진을 참고한 분홍 8꽃잎, 7색 구슬, 흰 중앙판·금색 음표의 절차적 3D 모형입니다.
- 요술봉: Peperuto Poron의 형태를 참고한 절차적 3D 모형입니다. 공식 원본 3D 에셋은 아닙니다.
- 캐릭터: 사용자가 제공한 레미·사랑이·메이 원화를 그대로 사용합니다. 메이는 제공된 상반신 이미지 범위입니다. **캐릭터는 2D 원화이며, 영상과 같은 완전한 3D 캐릭터/의상 변신은 구현되지 않았습니다.**
- 참고 영상과 의상·소품에 서로 다른 시즌/더빙이 섞여 있습니다. 현재 결과는 사진과 제공 이미지 기반의 인터랙션 프로토타입으로, 영상과 프레임·대사·음성까지 동일한 복제본은 아닙니다.
- 브라우저 내부 설정, 확장 스토어, 일부 PDF/보호된 페이지에는 브라우저가 확장 삽입을 금지합니다. 사이트 접근 권한을 허용한 일반 웹페이지에서 사용합니다. 파일 URL은 확장 설정의 파일 접근 허용이 추가로 필요합니다.
- WebGL을 사용합니다. 비활성 탭에서는 애니메이션을 멈추고, WebGL 오류/직접 비디오 전체화면에서는 기본 커서로 복구합니다. OS의 동작 줄이기 설정이 켜져 있으면 입자를 줄입니다.

다른 컴퓨터에서 이어서 작업하는 절차는 [HANDOFF.md](HANDOFF.md)에 정리되어 있습니다.

## 개발과 확인

```sh
npm ci
npm run check
npm run dev
```

체험: http://127.0.0.1:4173

빌드 결과는 `dist`입니다. 네트워크에서 코드를 가져오지 않고 Three.js와 모든 원화를 로컬 번들에 포함합니다. Chrome 120 이상을 대상으로 빌드합니다.

자동 테스트 28개: 캡처 권한/포커스/탭 전환 경합/서비스 워커 재시작 간격, 클릭과 길게 누르기/드래그/취소, 설정 복구, 음소거/음성 길이/스크롤 오디오, 구슬 챔버 경계, 7색 발광 순환, 3D 자원 해제. 로컬 체험 화면의 3D 출력, 캐릭터 전환, 기본 커서 복구와 실제 PNG 다운로드를 브라우저에서 확인했습니다. 설치된 Chrome/Edge의 실제 captureVisibleTab 저장 흐름과 macOS는 별도 실기기 검증이 필요합니다.
